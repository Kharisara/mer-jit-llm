IPD Prototype – Kesara Harisara Punchihewa (20220009)

This folder contains the working prototype for the IPD.

How to run:
1. Create a virtual environment
2. pip install -r requirements.txt
3. python run_ipd_demo.py

The prototype demonstrates:
- Policy-first intervention control
- Deterministic offline replay
- Enforced non-intervention
- Comparison with unsafe end-to-end baseline

No live users or online learning is involved.
